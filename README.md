# 📝 To-Do List App

A simple To-Do List web application built using **HTML, CSS, and JavaScript**.  
This project helps users add and delete daily tasks in a clean and interactive UI.

---

## 🚀 Features

- Add new tasks
- Delete tasks
- Simple and responsive UI
- Beginner-friendly project
- Real-time DOM manipulation

---

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
